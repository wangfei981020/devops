## 🔴 P1-防火墙：高危判定放宽 + 手动消除

**现状**：`fwHighRisk`（[network_resources.go:36](/Users/tom/vscode/devops/opsplatform-cmdb-backend/handlers/network_resources.go#L36)）= 入站 + allow + 源含 `0.0.0.0/0` + **命中敏感端口(22/3389/3306/6379/5432…)或全端口**。→ 443/80/2181 等对 `0.0.0.0/0` 全网放行但非敏感端口的**不算高危**（截图 24 条仅标 1 条）。

**要改**：
1. 判定放宽——**只要「入站 + 源含 `0.0.0.0/0`」就默认高危**，不看端口（443/80/2181 全算）。
2. **手动消除高危**：用户手动标"已确认安全/忽略高危"的规则才不显示红；可取消恢复。复用现有忽略模式（域名/证书/主机头忽略那套）。
3. 数据：`cloud_firewalls` 加 `risk_ignored` + `risk_ignore_reason`（新 migration）。
4. 接口：`PUT /cloud-firewalls/:id/risk-ignore`（忽略/取消 + 原因，非原生弹窗用 ElMessageBox.prompt）。
5. 前端：行内"消除高危"动作；已忽略灰标 + hover 原因；"只看高危"排除已忽略；`high_risk` 计算= 全网放行 AND NOT risk_ignored。
6. `high_risk` 现在是入库时算并存列——放宽后存量需回填/重算（同步时重算，或 migration 批量刷）。

## 🟡 P3-成本页：改成可视化图表 + 多维分析 + 环比归因

**现状**：主机页有"成本费率"弹窗（费率档位可编辑）+ 列表按机显示 日均/本月估/累计，但**没有聚合图表、没有维度下钻、没有环比对比**。

**要做**：
1. **成本图表**：按**月**展示，可按 **厂商 / 项目 / 单台机器** 三个维度筛选下钻，都能看到。
2. **整体项目资源使用概览**：一屏看各项目资源用量/花费占比。
3. **自定义对比（环比归因，重点）**：选两个月对比（如本月 vs 上月），要能**详细回答"为什么这个月钱变多、怎么多的"**——是新开机器？磁盘扩容？机型升配？停机变运行？逐项列出**成本差异明细**（新增/删除/变配的资源 + 各自增减金额）。
