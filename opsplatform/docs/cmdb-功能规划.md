# CMDB 系统功能规划

> 状态：**规划中（范围待定稿）** ｜ 日期：2026-06-16
> 由来：最初是「免费证书管理（Web + 自动续期 + 到期提醒）」的需求，升级为做一个 **CMDB（配置管理库）**，把域名管理重写进去，证书作为其中一类资产。
> 本文档是规划基线，重启/换会话后据此恢复上下文继续设计。

---

## 1. 背景与目标

统一管理 IT 资产（配置项 CI）+ 资产间关系的中心库。域名、证书是首批 CI 类型，未来扩展主机、应用、数据库、负载均衡、云/K8s 资源等。
**最初动机（必须满足）**：免费证书（ACME）Web 管理 + 自动续期 + 到期提醒。

## 2. 现状 / 可复用资产

- **`opsplatform-domain-backend` 已有**：`domains`（域名）、`registrars`（注册商，含 dnspod/aliyun/cloudflare/tencent 等 DNS 厂商 API 凭据）、`settings`、`overrides`、`sync`、`/domains/check-cert`、`/domains/check-expiry`。
  - **域名管理计划重写进 CMDB**；DNS 厂商凭据可直接复用做证书 **DNS-01** 验证（能签泛域名、不需公网入站）。
- 体系：Go+Gin 后端 / Vue3+ElementPlus 前端 / MySQL（本地 mysql-deploy:13307）/ K8s（namespace opsplatform，NodePort）/ 本地 Harbor `localhost:8070`；接 SSO、权限中心、alert 平台（飞书/告警）。

## 3. 完整功能清单（八模块 + 优先级）

优先级：🔵 地基（不做就不算 CMDB）｜🟢 本场景必备｜⚪ 后期扩展

### 一、配置项（CI）管理 —— 核心
- 🔵 CI 类型/模型定义（自定义资产类型、图标、分类）
- 🔵 CI 字段/属性管理（专属属性、必填、校验、枚举、默认值）
- 🔵 CI 实例增删改查 + 批量导入/导出（Excel/CSV）
- 🟢 生命周期状态（在用/闲置/下线/报废）
- 🔵 通用元数据（负责人、所属业务、环境 PROD/UAT、标签、备注）
- 🟢 唯一性约束 / 防重复录入

### 二、关系管理 —— CMDB 的灵魂
- 🔵 CI 间关系建模（保护/部署/解析/依赖/归属…）
- 🟢 关系类型自定义
- 🟢 拓扑/关系图谱可视化
- ⚪ 影响分析（改/删一个 CI 谁受影响）
- 🟢 链路追溯（域名→证书→LB→应用→主机）

### 三、具体资产类型
- 🟢 域名（注册商/到期/解析/状态）—— 重写现有
- 🟢 证书（CA/绑定域名/到期/自动续期）—— 核心诉求
- ⚪ 主机/服务器（IP/配置/OS/机房或云）
- ⚪ 应用/服务、数据库、中间件、负载均衡、K8s 资源、云资源

### 四、自动发现 / 数据采集
- 🟢 从 DNS 厂商同步域名、扫描证书到期
- ⚪ 从云/K8s 自动发现资源
- ⚪ 数据对账（发现 vs 录入差异）
- 🟢 定时同步任务

### 五、生命周期自动化（证书需求落这里）
- 🟢 证书 ACME 自动签发 / 自动续期 / 自动部署
- 🟢 到期提醒（域名 + 证书，接 alert/飞书）
- ⚪ 状态流转、工单/审批触发

### 六、查询 / 视图 / 大盘
- 🔵 多条件筛选 + 全文搜索
- 🟢 资产大盘（按类型/环境/到期统计）
- ⚪ 自定义视图、导出报表

### 七、权限 / 审计 / 合规
- 🟢 RBAC（按类型/字段/环境授权，接 SSO/权限中心）
- 🟢 操作审计（谁改了什么）
- ⚪ 变更历史/版本（CI 快照、diff、回溯）
- ⚪ 数据质量检查（缺负责人、将过期、孤儿 CI）

### 八、集成 / 开放
- 🟢 对外 API / Webhook（给发布、监控、告警消费）
- 🟢 接 SSO / 权限中心 / alert 平台

## 4. 第一期范围建议（待用户确认）

第一期 = **域名 + 证书**，把 **CI 模型 + 关系骨架** 立住，证书做全自动 ACME，其余 ⚪ 后期迭代。理由：有现成基础（domain-backend）+ 最快交付证书核心诉求 + 不把 CMDB 底座做歪。
> ⏳ 待用户最终圈定第一期模块清单。

## 5. CMDB 数据建模选型（待决策）

- A) 每类型一张专属表（强类型、查询直观，加类型要建表）
- B) 通用 CI 表 + 动态属性(JSON/EAV)（灵活、加类型不改库，查询/校验复杂）
- **倾向混合**：核心类型（域名/证书/主机）专属表，长尾类型动态属性。
